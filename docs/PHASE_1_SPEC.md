## 1. Objective

Build a minimal, real desktop application with:
- Functioning FastAPI Python backend.
- SQLite persistent database with SQLAlchemy 2.x and Alembic migrations.
- Centralized logging with credential redaction.
- Health-check and hardware diagnostics endpoints.
- React + TypeScript + Vite frontend with rich aesthetics (Material Design 3 dark mode, glassmorphism).
- Dashboard and diagnostics screen reflecting actual backend and database state.
- Chat screen with conversation threads and honest assistant responses.
- Automated tests passing on backend and frontend.
